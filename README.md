# Website FKWS Kobar

Website statis Forum Komunikasi Wali Santri Kobar menggunakan HTML, CSS, dan JavaScript sederhana.

## Halaman
- `index.html` — Beranda
- `profil.html` — Profil, visi, misi, nilai
- `berita.html` — Berita/pengumuman dengan pencarian
- `direktori.html` — Direktori pesantren contoh dengan pencarian
- `pendaftaran.html` — Formulir pendaftaran anggota (front-end saja)
- `kontak.html` — Kontak dan formulir pesan (front-end saja)

## Menjalankan
Buka `index.html` di browser, atau jalankan dengan ekstensi Live Server di Visual Studio Code.

## Publikasi ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `fkws-kobar`.
2. Unggah semua file dan folder ini ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai dan buka URL GitHub Pages yang diberikan.

## Catatan
Ini merupakan template front-end statis. Formulir belum menyimpan data, belum ada login/admin/backend/database. Nama pesantren, tanggal berita, email, dan kontak contoh perlu diganti dengan data resmi sebelum dipublikasikan. Desain menggunakan Google Fonts; jika offline, font cadangan akan digunakan.
